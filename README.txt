SKY ARCH LAB — website package

Files:
- index.html: page structure and content
- style.css: responsive design and layout
- script.js: mobile navigation, project filters, active navigation
- assets/hero-architecture.jpg: local hero image extracted from the supplied design reference

Publish on GitHub Pages:
1. Open your repository in GitHub.
2. Upload index.html, style.css, script.js and the assets folder.
3. Commit the changes to the branch/folder configured for GitHub Pages.
4. Open Settings > Pages to confirm the source if the site does not publish automatically.

Notes:
- Project card photographs are loaded from Unsplash and therefore require an internet connection.
- Replace hello@skyarchlab.example and the sample social details with your own contact information.
- Project names and visuals are concept/sample portfolio content; edit them to reflect your actual work.
